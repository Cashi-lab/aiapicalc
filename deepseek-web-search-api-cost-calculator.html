Cut your tool bill

  • Only successful requests bill — failed searches don't count; monitor your retry loop so it doesn't silently double-bill on success.
  • Cache search results — identical queries inside your TTL hit your own cache instead of the API.
  • Batch OCR by document — 1,000-page pricing means a 5-page PDF costs ~$0.0011; don't re-parse unchanged files.
  • Promo speech rates are live now — ASR at $0.058/hour is ~$1.16 for a 20-hour backlog; budget the list price for after the promo ends.

FAQ

How much does the DeepSeek Web Search API cost?

$0.75 per 1,000 successful requests (~$0.00075 each). The Fetch API for URL reading is the same $0.75 per 1,000.

How does it compare to OpenAI/Anthropic search?

Both bill ~$10 per 1,000 web-search tool calls — DeepSeek is ~13× cheaper on the tool fee itself.

How much is OCR and document parsing?

$0.225 per 1,000 pages, shared line item for file parsing and the OCR API.

Does the search price include LLM tokens?

No — tokens for the model reading results bill separately at your model's rates.
