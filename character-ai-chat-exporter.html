FAQ

Does it work on phone?

Chrome on Android can do it via "Request desktop site" + a console app, but it's fiddly. Use a desktop browser — two minutes there beats thirty on mobile.

Token not found automatically?

Open F12 → Application → Cookies → https://character.ai and copy the web_token value. Paste it into the prompt. If requests still return 401/403, log out and back in — tokens rotate.

Where do I find the chat ID manually?

Open the chat, F12 → Network tab, click any message scroll — look for a request to neo.character.ai/turns/<uuid>/. That UUID is the chat ID. Or just leave the prompt blank: the script lists your recent chats with their IDs.

Which file should I keep?

JSON is the master copy (every field, lossless). TXT/MD are for reading, CSV is for spreadsheets. Disk is cheap — take all four.

Is this allowed?

You're exporting your own data with your own credentials through the same API the web client uses. It's the same thing the official export does, faster. Still, unofficial is unofficial — internal APIs can change any day.
