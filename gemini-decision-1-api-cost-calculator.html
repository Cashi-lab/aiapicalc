Why it's cheap: bill the context once, ask 1,000 questions

Decision 1's pricing pattern rewards volume. You pay to prefill the shared context once, then fire up to 1,000 questions in the same request — each answer costs only its own input tokens, and outputs are free. Cut your Decision 1 bill

  • Batch your questions — the shared context is billed once per request; 1,000 questions in one request beat 1,000 requests by ~200× on per-question cost.
  • Trim question phrasing — at $0.10/M, every 40-token question costs $0.000004; shorter prompts scale directly.
  • Don't re-send static context — caching isn't available, so keep each request's context to what the questions actually need.
  • Prototype on the free tier — input is free up to 10,000 requests/day at 200 RPM.

FAQ

How much does the Gemini Decision 1 API cost?

$0.10 per 1 million input tokens; output tokens are free (the model emits zero output tokens). A request with a 10K-token context and 50 questions costs about $0.0012.

Why is Gemini Decision 1 so cheap?

It bills only input tokens, and the shared context is counted once — up to 1,000 questions can ride the same prefill. The intended pattern is: bill the context once, then ask many questions.

What are the rate limits?

Free tier: 200 RPM, 50,000 TPM, 10,000 RPD. Tier 1: 1,500 RPM, 1M TPM, 50,000 RPD. Tier 2/3 scale to 4M/10M TPM with unlimited daily requests. The Batch API is not supported.

Does Gemini Decision 1 support caching or batch?

No — context caching is not available and the Batch API is not supported for this model.
