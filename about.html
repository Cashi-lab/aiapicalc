About AI API Calc

Know your bill before you build.

AI API Calc is a collection of free calculators for AI model APIs. Every price on this site is pulled from official provider documentation or public model listings, and each page shows its verification date.

What we cover

  • LLM token pricing (input / output / caching / batch)
  • Realtime voice APIs (per-minute audio + PSTN)
  • Image generation APIs (per-image by resolution)
  • Video generation APIs (per-clip)

Editorial policy

  • Prices are verified against primary sources on the date shown per page.
  • We are independent — not affiliated with OpenAI, Google, Meta, xAI, Anthropic, Mistral, or Kling.
  • Calculators run entirely in your browser; nothing you type is sent anywhere.
