Typical workloads

  • Contact-center bot (1,000 agent-min/day, Mistral Small 4): 1,000 × $0.04 × 30 = $1,200/mo all-in.
  • Meeting transcriber (2,000 min/day batch Mini): 2,000 × $0.0035 × 30 = $210/mo.
  • Realtime agent pipeline à la carte: realtime STT $0.008/min + TTS at ~1,500 chars/min ≈ $0.0195/min → ~$0.028/min before LLM tokens — the $0.04/min bundle is cheaper unless you already run your own LLM.
  • Audiobook / narration (300k chars): 300,000 × $13/1M = $3.90 one-off.

Cost-cutting levers

  • Batch instead of realtime when latency allows: Mini batch $0.0035 vs realtime $0.008 — 56% cheaper per minute.
  • Use the bundled agent API ($0.04/min) instead of stitching STT + LLM + TTS yourself if Mistral Small 4 is good enough for reasoning.
  • Strip fillers before TTS — TTS is billed per character, so removing disfluencies/hesitations from agent replies cuts the $13/1M bill directly.
  • Self-deploy for sovereignty — Voxtral 3 ships for on-prem; at high volume the API convenience premium is worth recalculating.

FAQ

Is Voxtral 3 cheaper than Whisper or ElevenLabs?

Mistral positions Voxtral Speech 3 ($13/1M chars) below OpenAI TTS-1, Deepgram, ElevenLabs Flash and Gemini Flash for comparable TTS workloads, and the Small Transcribe model beats Whisper, Scribe v2 and Gemini 3.5 Transcribe on multilingual benchmarks at $0.0040/min. Run your own numbers above.

Does the $0.04/min agent price include transcription and speech?

Yes — the voice-agent API price is all-in for the streaming pipeline (listen, reason with Mistral Small 4, speak). Only if you swap in a different reasoning model does it become $0.08/min.

Is there a free tier?

Mistral typically offers trial credit on new console accounts; the rates here are the official list prices with no subscription. Check the Mistral console for current promotions.

Where do these prices come from?

Mistral's official Voxtral 3 announcement (mistral.ai/news/voxtral-3), fetched October 21, 2026. Prices are USD list rates on Mistral's EU-hosted API.
