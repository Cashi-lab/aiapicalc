FAQ

How much does the MiniMax H3 Image API cost?

$0.02179 per 1K image, $0.02333 per 2K, and $0.06879 per 4K list — currently $0.03439 with a limited-time 50% discount. Highspeed is $0.03529 / $0.03622 at 1K / 2K.

How is it billed?

Per token: $2.30 per 1M input text, $1.50 per 1M input image, $3.80 per 1M output image tokens. MiniMax converts those into the per-image examples above.

Is 4K worth it?

At list price 4K is 3.15× a 1K image. With the live promo ($0.03439) it is about 1.6× — that is the window to render finals at 4K.

Do reference images change the price?

Yes. Editing with 1 reference at 1K is $0.02654; with 3 references it is $0.06037 — roughly 2.3×.
